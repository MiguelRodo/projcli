Install the development preview

Download a checked binary. No Rust compiler or administrator access needed.

WarningTry it on a disposable project

Use sample data or a disposable copy of your project. Production builds (proj build) can modify or remove files, and safety fixes are still pending. Never run production builds on the only copy of important work. Previews are not a security sandbox; code you run can still change files.

Choose the preview explicitly

The published v0.4.0-preview.1 is an early development release. These instructions pin that version. GitHub’s stable Latest release is still v0.3.0; it does not contain the current preview features or the new binary-delivery metadata.

Download Requirements
Linux / WSL Ubuntu x86-64 processor, glibc 2.35 or newer; Bash, curl and sha256sum or shasum. Ubuntu 22.04 or newer meets the glibc requirement; user-local installation was verified in WSL Ubuntu 24.04.
Windows x86-64 processor; use PowerShell 7 (pwsh) for the installer below.
macOS / ARM No binaries supplied for this preview.

You do not need Git, Rust, Cargo or administrator access to install these binaries. The Python tutorial additionally needs Python 3. Other analysis tools are needed only if your own scripts or reports use them.

Ubuntu and WSL Ubuntu

Run this inside Ubuntu, not in a Windows terminal. Check that uname -m reports x86_64 and getconf GNU_LIBC_VERSION reports glibc 2.35 or newer.

mkdir -p "$HOME/.local/bin"
installer="$(mktemp)"
curl -fsSL "https://raw.githubusercontent.com/MiguelRodo/projcli/bbd12edc8de9865a96b6145d0c7702f1300cb1a8/install-local.sh" -o "$installer" &&
  PROJ_RELEASE_VERSION=0.4.0-preview.1 \
  PROJ_INSTALL_DIR="$HOME/.local/bin" bash "$installer"
rm -f "$installer"
export PATH="$HOME/.local/bin:$PATH"
hash -r
proj --version

Expected version: proj 0.4.0-preview.1.

The script comes from the reviewed source commit. It downloads the pinned Linux binary, checks its SHA256 against the release manifest, and installs it as ~/.local/bin/proj. It replaces an existing proj in that folder only after verification succeeds. No sudo or local compilation is involved.

Windows

Open PowerShell 7 (pwsh) as your normal user:

$installDir = Join-Path $env:USERPROFILE ".local\bin"
New-Item -ItemType Directory -Force -Path $installDir | Out-Null
$installer = Join-Path ([IO.Path]::GetTempPath()) ("proj-install-" + [guid]::NewGuid() + ".ps1")
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/MiguelRodo/projcli/bbd12edc8de9865a96b6145d0c7702f1300cb1a8/install.ps1" -OutFile $installer
$env:PROJ_RELEASE_VERSION = "0.4.0-preview.1"
$env:PROJ_INSTALL_DIR = $installDir
& $installer
Remove-Item -LiteralPath $installer
$env:Path = "$installDir;$env:Path"
proj --version

Expected version: proj 0.4.0-preview.1.

The script checks the Windows binary’s SHA256 before installing proj.exe in $HOME\.local\bin. It does not change system settings or require an administrator terminal. This installer is checked with PowerShell 7; these instructions do not claim Windows PowerShell 5.1 compatibility.

Finding the command later

The PATH lines above make the command available in the current terminal. In a new terminal, repeat that PATH line or add the installation folder to your own user PATH. The installer does not make that permanent change for you.

Another program can also be named proj. Check command -v proj in Ubuntu or Get-Command proj in PowerShell, then proj --version, if you see unexpected help or results.

What the checksum proves

The installer requires the release’s version.txt and exactly one matching entry in checksums.txt. A missing or incorrect checksum stops installation before the existing binary is replaced. For a manual download, use sha256sum on Linux or Get-FileHash -Algorithm SHA256 in PowerShell and compare the result with the manifest’s exact filename entry before running it.

The manifest comes from the same GitHub release. Checksums detect corruption and mismatches; they are not independent signatures or proof of a reproducible build. The release also includes source-commit.txt and version.txt. The reviewed source is bbd12edc8de9865a96b6145d0c7702f1300cb1a8.
