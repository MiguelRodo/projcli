# Cross-platform CLI for version-linked project builds

This repository contains a Rust CLI and reusable Rust modules for version-linked
research builds. Future R, Python and Julia frontend boundaries remain explicit
architecture decisions; their availability is not implied by the Rust library.

Read the [behavior contract](docs/behavior.qmd) for confirmed root and execution
semantics, open decisions and known implementation gaps. The
[build flow](docs/flow.qmd) describes the current implementation and is not the
authority for intended product behavior.
